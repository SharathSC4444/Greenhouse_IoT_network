# Greenhouse_IoT_network

This project was done in collaboration by Sharath Chandhar S and Sharvesh Muralidharan as a part of our end semester project for Computer Communication Networks. The idea of the project is to develop a scalable model of a modern greenhouse that relies on automated IoT devices to perform the many functions in a greenhouse, and using the principles we've learnt throughout the semester to establish a network wherein people can both within the local network and those accessing the greenhouse IoTs from far away can manage it with ease.


The design of a VLAN-segmented Cisco Packet Tracer network that connects greenhouse IoT sensors, actuators and controllers to a central IoT server, isolates them from office devices and enables secure remote monitoring and control through a single public IP.
